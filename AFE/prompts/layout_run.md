# Layout run prompts for Atharv (L2a -> L4), ready to paste into Claude Code

Written 2026-11-18 by the monitoring session; updated 2026-11-20 after the audit (Decision 44), F1 (Decision 46) and the 24-pad decision (Decision 45). Every prompt Atharv needs is in this file. Phase LP (Jojo's machine, AFE/prompts/layout_prep.md) adds the layout kit (AFE/layout/SPEC.md, floorplan.json, ACCEPT.md, RUNBOOK.md, scripts/gate.py, scripts/check_env.sh) and may refine these prompts; always `git pull` and use the version of this file on origin.

## How to use (Atharv)
- Environment: IIC-OSIC-TOOLS image 2026.04, PDK gf180mcuD at /foss/pdks, repo at /foss/designs/ENGN2912E_Project.
- One fresh Claude Code session per phase, started in the repo root. Before each phase: `git pull`. After the agent stops: `git push`, send Jojo the summary for information (do not wait for an answer), start the next phase.
- Model: Sonnet 5.5; HIGH effort for L2a, L1a, L1d, L3a, default effort for the rest. If a phase stops on "the same failure twice", start a new session at HIGH effort for that fix only.
- Run order (one phase at a time on one machine):
  | # | Phase | What | Start when | Target |
  |---|---|---|---|---|
  | 1 | L2a | amplifier channel: flow check, then DRC + LVS | now | 11-21 |
  | 2 | L1a | ADC analog cell: DRC + LVS | AFE/NOTES.md has "LP findings" and Decision 47 (ACCEPT.md approved) | 11-21 |
  | 3 | L1d | digital macro afe_dig, finalise LP's trial hardening | after L1a (or in parallel with L1a if RAM allows, common rule 4) | 11-21 |
  | 4 | L2b | amplifier PEX + post-layout sims | after L2a and Decision 47 | 11-22 |
  | 5 | L1b | ADC PEX + post-layout sims | after L1a | 11-22 |
  | 6 | L3a | top assembly, full-chip DRC + LVS | after L1d, L2b, L1b | 11-23 |
  | 7 | L3b | critical-net PEX + end-to-end transient | after L3a | 11-24 |
  | 8 | L4  | submission package | after L3b | 11-25 |
  F1 (audit fixes) and LP (layout kit) run on Jojo's machine; F1 is done (e3b04a2). Do not run them.
- While LP runs on Jojo's machine (during L2a), L2a writes only under AFE/layout/amp/, AFE/layout/FLOW.md and AFE/layout/NOTES_L2.md. From L1a on, everything runs on Atharv's machine and phases write AFE/NOTES.md (common rule 7).
- If a gate fails: follow the decision ladder in AFE/layout/ACCEPT.md; only if no entry applies, the agent writes AFE/layout/BLOCKED.md and stops, then send it to Jojo.
- If late, cut in this order: (1) L2b/L1b at typ only, (2) skip the optional deep n-well, (3) N = 2 channels (Decision 45 fallback, ACCEPT.md ladder).

## Common rules (every prompt below includes "Follow AFE/prompts/layout_run.md common rules")
1. Read AFE/NOTES.md (all Decisions and the Results log), AFE/review/AUDIT.md sections 2, 3 and 4.9, AFE/TAPEOUT.md, AFE/layout/PLAN.md, and once they exist AFE/layout/FLOW.md, AFE/layout/SPEC.md, AFE/layout/floorplan.json and AFE/layout/ACCEPT.md, before working. Every phase after L2a requires Decision 47 (ACCEPT.md approved) in AFE/NOTES.md; if it is missing, stop and say so. Where SPEC.md / floorplan.json / ACCEPT.md give a number, a pin position or a limit, they win over the prompt text below.
2. All geometry is generated by re-runnable scripts (KLayout Python, `klayout -b -r`), N is a parameter, outputs under AFE/layout/. No hand-drawn GDS.
3. Sign-off DRC = the official gf180mcuD KLayout deck; LVS = netgen (always `-batch`, run with a timeout and waited on by PID; `netgen --version` hangs). LVS netlists use cap_mim_2f0_m4m5_noshield (sims used m2m3: substitute by script and record it).
4. Machine limits: ~8 GB RAM, limited disk. At most 3 heavy jobs (ngspice, magic, klayout DRC) in parallel. Scratch under AFE/layout/.ptmp (git-ignored) and delete it at the end. Wait on PIDs, never `pgrep -f`/`pkill -f` (they match their own command line). No `timeout 1800` wrappers around long simulations.
5. Never open *.raw, GDS or PEX netlists in full; use grep/summary scripts. Corners: typical 27 C, ff 85 C, ss -40 C only, unless a result is within 10 % of a limit.
6. If a step fails the same way twice, apply the matching entry of the AFE/layout/ACCEPT.md decision ladder; if none applies, write AFE/layout/BLOCKED.md with the evidence and stop instead of trying a third fix. Numbers only from saved logs; mark estimates as ESTIMATE.
7. Write a "<phase> findings" section in AFE/NOTES.md and a Results-log row (L2a only: in AFE/layout/NOTES_L2.md, because LP edits AFE/NOTES.md on another machine at the same time; the first phase after L2a copies NOTES_L2.md into AFE/NOTES.md as "L2a findings" + its Results-log row, unchanged, if AFE/NOTES.md has no "L2a findings" yet); `git pull --rebase` and commit locally with a clear message; do not push (the human pushes). Do not write a numbered Decision (the human/monitoring session does). Stop at the end of the phase.
8. Simulation rules (Decision 43a, from X2): every transient with switching uses `.options abstol=1e-12` (keep gmin 1e-16 reltol 1e-4 vntol 1e-7 chgtol 1e-17; abstol 1e-15 causes "timestep too small" aborts); one ngspice thread per job (job-local .spiceinit with `set num_threads=1`; the system default is 8 threads and 5-35x slower); never pipe ngspice through `cut` or truncate its log; every supply model with pad L gets ~1 pF per pad to board ground; re-run an aborted job once with a slightly different step cap. Reuse AFE/adc/scripts/x2lib.py (closed-loop PWL replay) for any ADC transient; XSPICE co-simulation is broken here.
9. Process option (verified in the PDK decks and the organizer table): variant D = 5 metals, 11 kA top metal, MIM option B (cap_mim_2f0_m4m5_noshield), high-resistance poly 1 kOhm/sq ONLY: `ppolyf_u_3k` does not exist in this variant (Decision 44a). Run KLayout DRC and LVS with --variant=D.
10. LVS reference netlists are written by a script from the simulation netlists with the substitutions of AFE/review/AUDIT.md 4.9.3 (AFE/layout/scripts/mk_lvs_netlists.py from F1, output AFE/layout/lvs/); never edit a simulation netlist for LVS.
