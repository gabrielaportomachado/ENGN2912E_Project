# R14 report (2026-11-21; Claude Sonnet 5.5 / high; REVIEW.md item R14 = Decision 54: real 4-channel digital RTL, the 80-SCLK SPI frame, macro re-hardened)

## 1. Summary and verdict
Decision 54 is implemented exactly: a new `adc_top #(.N(4))` with the 80-edge frame (config word with WR, status word with the sync pattern 1010 and DOUT bit 15 valid at edge 1, commit at edge 17 only if WR = 1, channel words `{ID[1:0], 00, code}`, edges beyond 80 ignored), `dbs_ctrl #(.N(4))`, a 4-wide top, a 4-channel `afe_dig` wrapper, and the macro hardened with the frozen recipe.
**Macro: 424.48 x 86.24 um (slot 425 x 86.24 um), 58.6 % utilisation (flow), 91 flops, STA met at 5 corners, 0 slew / cap violations, KLayout DRC variant D 0, antenna 0, Magic DRC / LVS 0.** Tap limits (a) 22.22 ns, (c) 136.78 ns, captured-decision slack 128.32 ns; 17.0 pC per SCLK cycle (tt). The floorplan was rebuilt with `dig_h = 86.24` (amp_ch slot 222 x 336.88 um, +63.6 um of height for the unchanged cell), `floorplan.py check` 20 PASS 0 FAIL, LVS references A / B / C PASS (996 cell instances in afe_dig).
**Gate L1d: PASS; gates L2a, L1a, L2b, L1b: PASS** (cells unchanged; the final gate output is in section 5).
Verification: `adc_top` 31 simulation runs PASS (bit-by-bit frame, every code on every channel, 5 corners x 4 frequencies, equivalence of the conversion phase with the legacy `adc8_top`, the legacy `tb_adc8` still PASS); `AFE/top/run_top_sim.sh` RESULT PASS; `run_top_sim.sh dig` EQUIV PASS; gate-level audit (36 runs): only the accepted assertions fail.

## 7. Deviations
1. **Height 86.24 um, not the routable minimum 78.4 um.** R14 says "the smallest height that routes cleanly". 78.4 um (20 rows) also routes and passes the flow VERDICT, but its utilisation is 64.7 % and 82.32 um gives 61.4 %, both above the 60 % that ACCEPT.md A-4 allows and that `floorplan.py check` 4b enforces; 86.24 um (58.6 %) is the smallest height inside the limit. For the user to confirm (a lower height would need an A-4 extension; the extra 7.8 um go to the channel slots).
2. `floorplan.py`: the estimate `EST['afe_dig_cells']` was the N = 8 figure 33,661 um2 and would have failed check 4b for any height below 132 um; it is now the as-built 18,879 um2 (std cells of this run). Not a protected file.
3. `AFE/layout/scripts/gate.py`: (a) `DIG_ALLOWED` X5.after33d -> X5.after17d (the same accepted failure under its new name: a RSTN pulse after the commit edge, followed by DIN data, makes the restarted frame commit garbage; with DIN = ones it is deterministic); (b) the L1d die-size check compares with the slot of floorplan.json (was 820 x 110 um). The other three accepted assertions are unchanged.
4.
